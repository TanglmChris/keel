## MODIFIED Requirements

### Requirement: Target-native subagent gate is documented

Keel resident protocol and generated overlays MUST leave helper and in-scope implementation organization to the model, without extra user activation or mandatory tier declaration. They MUST state the helper read-only boundary, implementation task authority and matching active guard, master Review and rerun duties, and host policy limits. They MUST NOT force subagent use, parallelism, number or concrete model.

#### Scenario: Bounded model choice is documented
- **WHEN** protocol or generated apply/archive surfaces are read
- **THEN** helper choice requires no extra activation; implementation uses task write authority and a matching active guard, and master owns completion
