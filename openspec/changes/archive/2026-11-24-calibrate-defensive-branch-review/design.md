## Decisions

- D1 — Score a proposed defensive branch by its concrete trigger, public requirement or failure, resulting state, and error visibility. Use a narrow positive and negative control for each workload. Use selected public Keel cases as calibration only.
- D2 — Compare anonymous patches on the same published task with exact input, permission, time and token conditions. Retain raw results and compare instruction versions before inferring any model effect. Do not generalize from the retrospective case sample or unidentified model history.
